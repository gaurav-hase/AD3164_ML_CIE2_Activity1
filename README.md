# Titanic Dataset Preparation and EDA

## Machine Learning CIE 2 – Activity 1

### 1. Introduction
This project focuses on dataset preparation, data cleaning and exploratory data analysis using the Titanic passenger dataset.

### 2. Dataset Information
- Dataset: Titanic Passenger Dataset
- Domain: Transport
- Source: https://www.kaggle.com/datasets/yasserh/titanic-dataset
- Format: CSV
- Target Column: Survived

### 3. Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### 4. Work Completed
1. Dataset loading and inspection.
2. Identification of numerical and categorical columns.
3. Missing-value analysis and handling.
4. Duplicate detection and removal.
5. Data consistency checking.
6. Exploratory Data Analysis (EDA).
7. Data visualization.
8. One-hot encoding.
9. Numerical feature standardization.
10. Exporting the prepared dataset.

### 5. Visualizations
- Age distribution histogram.
- Passenger survival count bar chart.
- Passenger fare box plot.

### 6. Output
The cleaned and prepared dataset is saved as `Titanic_Prepared_Dataset.csv`.

### 7. Conclusion
The activity demonstrates the importance of data cleaning, visualization, encoding and scaling before applying machine learning algorithms.
